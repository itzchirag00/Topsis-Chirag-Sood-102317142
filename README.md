Assignment4_TOPSIS – Chirag Sood (102317142)
Explanations:-

a. The given dataset containing multiple alternatives and criteria is used to perform decision-making analysis.

b. All criteria values are first normalized to remove the effect of different measurement scales and ensure fair comparison.

c. User-defined weights are applied to each criterion to represent their relative importance in the decision process.

d. The Ideal Best Solution and Negative Ideal Solution are determined based on benefit and cost criteria.

e. The Euclidean distance of each alternative from both the ideal best and negative ideal solutions is calculated.

f. A TOPSIS score is computed for every alternative using the relative closeness to the ideal solution.

g. Alternatives are ranked according to their TOPSIS scores, where Rank 1 represents the best choice.

h. The final output file includes the original dataset along with calculated TOPSIS scores and corresponding ranks.
